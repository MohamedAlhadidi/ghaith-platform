## 4. الرقابة الأبوية
- Google Family Link: يشرف على Android 6+ وChromebook؛ لا يشرف على أجهزة iPhone/iPad والحواسيب غير Chromebook؛ على Windows يعمل داخل Chrome فقط عند تسجيل دخول الطفل، ويمكنه تسجيل الخروج. support.google.com/families/answer/9116646 و7087030.
- Microsoft Family Safety على Windows 11: تصفية الويب في Edge فقط، وتحجب المتصفحات الأخرى عند تفعيلها؛ خيار "المواقع المسموح بها فقط" يقصر التصفح على قائمة بيضاء. support.microsoft.com/en-us/help/4027332.

## 5. التوصية النهائية
الواجهة React + TypeScript + Vite + vite-plugin-pwa (Workbox)؛ الخلفية .NET 10 Minimal API + EF Core 10 + SQL Server 2025 Express/LocalDB؛ التخزين: precache للتطبيق، Cache Storage/IndexedDB للحزم، persist() بعد التثبيت، عرض estimate() للأب؛ الصوت Azure F0 ar-OM؛ الاستضافة Cloudflare Pages + R2 + Tunnel/Access للـAPI على جهاز منزلي، ثم Azure F1 + Azure SQL المجاني عند الحاجة.
