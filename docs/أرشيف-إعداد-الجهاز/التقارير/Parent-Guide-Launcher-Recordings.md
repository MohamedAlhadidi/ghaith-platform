# دليل ولي الأمر: المشغّل البصري وتسجيل الأصوات وكلمات الأسبوع

27 أكتوبر 2026. كل ما في هذا الدليل يُنفَّذ من حسابك (seeb_) إلا ما يُذكر خلافه. لا يحتاج أي خطوة تقنية.

## 1. كيف يعمل المشغّل عند غيث

- عند دخول غيث يفتح المشغّل تلقائيًا ملء الشاشة بـ12 بلاطة. تمرير الفأرة على البلاطة ينطق اسمها، والضغط يفتحها.
- الخروج للكبار: اضغط Ctrl+Shift+Q، أو انقر 5 مرات سريعة على كلمة «للكبار» في الزاوية السفلية.
- إن أغلقه غيث بالخطأ، يفتحه من اختصار «مدرستي - غيث» على سطح المكتب.
- الصوت: إن وُجد تسجيل بصوتك للبلاطة يُشغَّل هو؛ وإلا يُستخدم صوت Windows العربي بعد تثبيته؛ وإلا تبقى البلاطة صامتة.

## 2. تسجيل أصوات البلاطات بصوتك (مرة واحدة، نحو 10 دقائق)

1. افتح تطبيق «مسجل الصوت» (Sound Recorder) من قائمة ابدأ في حسابك.
2. سجّل كل عبارة في ملف مستقل بصوت واضح وهادئ باللهجة التي تكلّمه بها في البيت:

| اسم الملف (بلا امتداد) | ما تقوله |
|---|---|
| اهلا-غيث | أهلًا غيث |
| اسمع-واقول | أسمع وأقول |
| الحروف | الحروف |
| الحرف-الناقص | الحرف الناقص |
| القصص | القصص |
| الجمع | الجمع |
| الساعة | الساعة |
| الون-واحكي | ألوّن وأحكي |
| اسجل-صوتي | أسجّل صوتي |
| تمارين-النطق | تمارين أستاذ النطق |
| كتبي | كتبي |
| english | English |
| كل-الالعاب | كل الألعاب |
| احسنت | أحسنت |

3. التسجيلات تُحفظ تلقائيًا في مجلد «التسجيلات الصوتية» داخل مستنداتك بصيغة m4a. أعد تسمية كل ملف بالاسم المطلوب في الجدول (الامتداد يبقى m4a؛ المشغّل يقبل m4a وmp3 وwav).
4. انسخ الملفات إلى المجلد:
   C:\ProgramData\ChildLearning\Launcher\أصوات
   سيطلب Windows موافقة مسؤول عند النسخ لأن المجلد محمي من تعديل الطفل؛ اضغط «متابعة».
5. لا حاجة لإعادة تشغيل شيء؛ المشغّل يقرأ الملفات في المرة التالية التي يُفتح فيها.

## 3. كلمات الأسبوع من أستاذ النطق (كل أسبوع، 5 دقائق)

المجلد عند غيث:
C:\Users\ghait\Documents\مدرستي\تمارين أستاذ النطق\

1. أنشئ مجلدًا جديدًا باسم الأسبوع التالي: الأسبوع-02، ثم الأسبوع-03، وهكذا. المشغّل يفتح الأحدث رقمًا تلقائيًا.
2. داخله أنشئ ملف «الكلمات.txt» واكتب كلمات الأخصائي كلمة في كل سطر (10 كلمات تقريبًا). المجلد الحالي الأسبوع-01 فيه خمس كلمات تجريبية (بيت، شمس، كتاب، قطة، تفاحة) استبدلها بكلمات الأخصائي.
3. اختياري لكنه مفيد جدًا: لكل كلمة صورة بنفس الاسم (مثل بيت.png أو بيت.jpg)، وتسجيل بصوتك بنفس الاسم (بيت.m4a). بلا تسجيل يُستخدم صوت Windows العربي بعد تثبيته.
4. ملف الكلمات يجب أن يكون بترميز UTF-8؛ المفكرة في Windows 11 تحفظه كذلك افتراضيًا.

## 4. جلسة التمرين مع غيث (15 إلى 20 دقيقة، بعد الواجبات)

1. افتح بلاطة «تمارين أستاذ النطق». تظهر الكلمات صفًا صفًا.
2. لكل كلمة: اضغط «اسمع»، ثم اطلب من غيث أن يقولها قبل أن يلمس شيئًا، ثم اضغط «سجّل» ودعه يقولها (4 ثوان)، ثم «اسمع صوتي» لتسمعاها معًا.
3. قيّم أنت: «قالها» أو «تقريبًا» أو «لم يقلها». التقييم يُحفظ في:
   C:\Users\ghait\Documents\مدرستي\سجل التقدم.csv
   وتسجيلاته في مجلد «تسجيلاتي». أرسل الملفين أو أرهما للأخصائي في كل زيارة.
4. أعد الكلمات نفسها بعد يومين وبعد أسبوع؛ التكرار المتباعد هو ما يثبّت الكلمة.
5. بعد الحاسوب: 10 دقائق لعب أو حوار بلا شاشة تستخدمان فيه الكلمات نفسها.

## 5. ما بعد إعادة التشغيل الثانية

- أخبرني لأثبّت الصوت العربي، فتنطق كل البلاطات والكلمات تلقائيًا حتى بلا تسجيلاتك.
- بعد تثبيته يمكنك أيضًا تفعيل «الراوي» (Narrator) بـ Win+Ctrl+Enter في حساب غيث ليقرأ أسماء الأيقونات بالعربية، لكنه ثرثار؛ المشغّل يغني عنه.
