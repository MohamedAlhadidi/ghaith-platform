# التشغيل المحلي والاختبار

## المتطلبات (مثبتة على هذا الجهاز بحساب seeb_)
Git 2.56، .NET SDK 10.0.403، Node.js 26 LTS، VS Code. قاعدة البيانات (SQL Server Express أو LocalDB) لم تُثبت بعد ولا تحتاجها الواجهة؛ التقدم يُحفظ في متصفح غيث (IndexedDB).

ملاحظة: سياسة تنفيذ PowerShell على الجهاز تمنع `npm.ps1`؛ استخدم `npm.cmd` و`npx.cmd` من PowerShell، أو شغّل الأوامر من موجه الأوامر (cmd).

## الواجهة (apps/web)

```powershell
cd C:\Users\seeb_\source\ghaith-platform\apps\web
npm.cmd install          # مرة واحدة
npx.cmd tsc -b           # فحص الأنواع
npx.cmd vitest run       # اختبارات المنطق (21 اختبارًا)
npm.cmd run build        # بناء الإنتاج مع عامل الخدمة في dist/
npm.cmd run preview      # معاينة النسخة المبنية على http://127.0.0.1:4173
npm.cmd run dev          # خادم التطوير على http://127.0.0.1:5173 (بلا عامل خدمة)
```

### تجربة غيث من حسابه (بلا نشر)
1. من حسابك شغّل `npm.cmd run preview` واتركه يعمل.
2. بدّل المستخدم إلى غيث (Win+L ثم اختر غيث) دون تسجيل خروجك.
3. في Edge افتح `http://127.0.0.1:4173/` ثم من قائمة Edge اختر "التطبيقات" ← "تثبيت هذا الموقع كتطبيق". المنفذ المحلي مشترك على مستوى الجهاز، والتثبيت من 127.0.0.1 مسموح بلا HTTPS.
4. بعد أول فتح تُخزَّن ملفات التطبيق محليًا في متصفح غيث؛ إن أُغلق الخادم يبقى التطبيق يعمل من النسخة المخزنة (بلا تحديث حتى يعود الخادم).

### لوحة الأب
من شاشة البداية اضغط "للكبار" أو افتح `#/parent`. الرمز الافتراضي عند أول استخدام 1234، ويُنصح بتغييره فورًا من اللوحة. الرمز يمنع التغيير العرضي فقط.

### أين تُحفظ بيانات غيث؟
في IndexedDB داخل ملف Edge لحساب غيث (قاعدة `ghaith-learning`). النسخة الاحتياطية من لوحة الأب (تنزيل JSON) واستيرادها من الزر المجاور. مسح بيانات المتصفح يحذف التقدم؛ لذلك خذ نسخة احتياطية دوريًا حتى تُفعَّل المزامنة.

## الخدمة (apps/api)

```powershell
cd C:\Users\seeb_\source\ghaith-platform\apps\api
dotnet build Ghaith.slnx
dotnet test Ghaith.slnx
dotnet run --project Ghaith.Api
```

الخدمة حاليًا هيكل فارغ من القالب؛ تُضاف نقاط المزامنة وقاعدة البيانات في مراحل لاحقة بعد توفر SQL Server.
