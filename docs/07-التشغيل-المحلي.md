# التشغيل المحلي والاختبار

## المتطلبات (مثبتة على هذا الجهاز بحساب seeb_)
Git 2.56، .NET SDK 10.0.403، Node.js 26 LTS، VS Code، ومتصفح Chromium لاختبارات Playwright. قاعدة البيانات لا تحتاجها الواجهة في المرحلة 0؛ التقدم يُحفظ في متصفح غيث (IndexedDB) مع تصدير JSON من لوحة الأب.

ملاحظة: سياسة تنفيذ PowerShell على الجهاز تمنع `npm.ps1`؛ استخدم `npm.cmd` و`npx.cmd` من PowerShell، أو شغّل الأوامر من موجه الأوامر (cmd).

## الواجهة (apps/web)

```powershell
cd C:\Users\seeb_\source\ghaith-platform\apps\web
npm.cmd install          # مرة واحدة
npx.cmd tsc -b           # فحص الأنواع
npx.cmd vitest run       # اختبارات المنطق (48 اختبارًا: المولدات عبر 1000 بذرة، الإتقان، الرفيق، التكيّف، المخطط)
npm.cmd run build        # بناء الإنتاج مع عامل الخدمة في dist/
npm.cmd run preview      # معاينة النسخة المبنية على http://127.0.0.1:4173
npm.cmd run e2e          # اختبارات المتصفح (جلسة كاملة، الاستئناف، Enter المزدوج، خريطة الكنز) على نسخة المعاينة
npm.cmd run dev          # خادم التطوير على http://127.0.0.1:5173 (بلا عامل خدمة)
```

### ما تراه في الجلسة (المرحلة 0)
1. اختيار شكل الأفاتار (مرة واحدة) ثم ترحيب الرفيق وهدف اليوم.
2. خط الأساس: ثمانية أسئلة بلا تلميح وبرد محايد (في أول جلسة، ثم كل خمس جلسات).
3. الشرح على الخريطة (خمس شاشات قصيرة).
4. نلعب معًا: مثال يحله الرفيق أمامه بالحركة، ثم سؤال بتلميح تلقائي، ثم سؤال بلا دعم.
5. وحدك: خمسة أسئلة بتمثيلات مختلفة (حركة، خريطة، بلا خريطة) مع تكيّف تلقائي.
6. أسئلة جديدة: ثلاثة أسئلة بلا تلميح، والنتيجة تظهر في النهاية.
7. النهاية: نجوم الجهد (نجمة لكل سؤال أكمله وثلاث للجلسة) ونشاط ورقي.
زر "توقف" يحفظ الموضع؛ إعادة الفتح تستأنف من السؤال نفسه خلال 12 ساعة. السؤال يُعرض بالبطاقات (العدد كبيرًا، والعملية في بطاقة خضراء، والمجهول "؟") وتُنطق جملته الكاملة في فقاعة الرفيق؛ وفي خط الأساس والتحقق يوجد زر "لا أعرف" يُسجَّل بوسم خاص بدل التخمين. المصطلحات من الكتاب: لوحة المائة، إلى أسفل/إلى أعلى، العقود، بين العقدين، نقطة المنتصف.

### تجربة غيث من حسابه (بلا نشر)
1. من حسابك شغّل `npm.cmd run preview` واتركه يعمل.
2. بدّل المستخدم إلى غيث (Win+L ثم اختر غيث) دون تسجيل خروجك.
3. في Edge افتح `http://127.0.0.1:4173/` ثم من قائمة Edge اختر "التطبيقات" ← "تثبيت هذا الموقع كتطبيق". المنفذ المحلي مشترك على مستوى الجهاز، والتثبيت من 127.0.0.1 مسموح بلا HTTPS.
4. بعد أول فتح تُخزَّن ملفات التطبيق محليًا في متصفح غيث؛ إن أُغلق الخادم يبقى التطبيق يعمل من النسخة المخزنة. التحديثات لا تُطبَّق تلقائيًا؛ يظهر زر "يوجد تحديث" في شاشة البداية.

### لوحة الأب
من شاشة البداية اضغط "للكبار" أو افتح `#/parent`. الرمز الافتراضي عند أول استخدام 1234، ويُنصح بتغييره فورًا. اللوحة تعرض: حالة المهارة بدليلها، "ما لاحظه رفيق" لكل جلسة مع اقتراح ورقي، أنماط الأخطاء، الجلسات، المحاولات بتفاصيل المراقبة (أول فعل، التردد، التلميحات، وسم الخطأ)، الإعدادات (الاسم، شكل الأفاتار، مدة الجلسة، الصوت)، قواعد الإتقان، والنسخ الاحتياطي.

### أين تُحفظ بيانات غيث؟
في IndexedDB داخل ملف Edge لحساب غيث (قاعدة `ghaith-learning`، الإصدار 2). النسخة الاحتياطية من لوحة الأب (تنزيل JSON) واستيرادها من الزر المجاور. مسح بيانات المتصفح يحذف التقدم؛ لذلك خذ نسخة احتياطية أسبوعيًا حتى تُفعَّل المزامنة (اللوحة تذكّرك).

## الخدمة (apps/api)

```powershell
cd C:\Users\seeb_\source\ghaith-platform\apps\api
dotnet build Ghaith.slnx
dotnet test Ghaith.slnx
dotnet run --project Ghaith.Api
```

الخدمة حاليًا هيكل فارغ من القالب؛ تُضاف نقاط المزامنة وقاعدة البيانات (SQL Server عبر EF Core) في المرحلة التالية بعد تجربة النموذج.

## الصوت
الملفات المسجّلة تُوضع في `apps/web/public/audio/<معرف>.mp3` وتُدرج في `apps/web/public/audio/audio-manifest.json` بالشكل `{ "files": ["c.welcome.1", ...]}`. بلا ملفات يستخدم التطبيق صوت المتصفح العربي **المحلي فقط** إن وُجد (الأصوات السحابية معطّلة حفاظًا على الخصوصية)، وإلا يبقى النص ظاهرًا في فقاعة الرفيق مع زر الإعادة. معرّفات جمل الرفيق في `src/avatar/script.ts`.
