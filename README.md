# منصة غيث التعليمية

منصة تعليمية شخصية تعمل دون اتصال، لطفل في الصف الثاني الأساسي بسلطنة عُمان، تبدأ بالرياضيات ثم الإنجليزية، وقابلة للتوسع عبر المواد والصفوف والأطفال.

## البنية

| المجلد | المحتوى |
|---|---|
| `apps/web` | واجهة غيث ولوحة الأب: React + TypeScript + Vite + PWA (Workbox) |
| `apps/api` | خدمة .NET 10 Minimal API + EF Core 10 + SQL Server 2025 Express |
| `content` | المنهج: خريطة الوحدات والدروس والمهارات، قوالب الأسئلة، وحزم الصوت والصور المعتمدة |
| `tools` | أدوات إدارة المحتوى وتوليد الصوت والنشر |
| `docs` | التصور المعتمد، التقارير، دليل الأب، دليل التشغيل والنشر |

## القواعد الثابتة

- كل التعليقات في الكود ورسائل الالتزام والتوثيق ونصوص الواجهة بالعربية؛ أسماء المعرّفات بالإنجليزية.
- لا أسرار في المستودع؛ التطوير بـ `dotnet user-secrets` والإنتاج بمتغيرات البيئة.
- ملفات الكتب المدرسية وبيانات الطفل لا تُرفع إلى المستودع (`content/sources` و`data` مستثناة).
- معرّف كل مهارة ثابت ومستقل عن رقم الصفحة، مثل `MATH.G2.S1.CA03-1`.
- تعديل المحتوى لا يمحو تقدم الطفل.

## التشغيل محليًا

يُستكمل بعد اكتمال المرحلة 5 (درس لوحة المائة).
